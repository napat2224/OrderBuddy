The image is a customer's order for a Thai restaurant: a handwritten note, a printed list or a chat screenshot.
Read every food item, quantity, phone number and address in it, and return the customer's COMPLETE current order as JSON.

Menu (name price | options | addons):
$menu

Current order (JSON): $current
Caption from the customer: $caption

Rules:
- items[].text: the menu name closest to what is written.
- qty: the number written (0-20); null when no number is written. Never guess 1.
- An item with 0 or crossed out: keep it with qty 0 (it will be removed).
- options and addons: only values listed for that item.
- Copy name, phone and address exactly as written; null when not visible. Never invent them.
- Keep items from the current order unless the image replaces them.
Return JSON only.
